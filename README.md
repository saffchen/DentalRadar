# Мой Стоматолог

Личный кабинет пользователя и личный кабинет стоматологической клиники. Карта клиник использует OpenStreetMap.

Нужны Java 17, Maven и Node.js. Из корня репозитория выполните:

```bash
./start.sh
```

Скрипт собирает интерфейс и запускает сервер. Откройте `http://localhost:8080`.

Данные лежат в `backend/data/db.json`. При пустом файле сервер создаёт три демонстрационные клиники.

Демонстрационные входы, пароль `demo1234`:

- Пользователь: `user@demo.local`
- Клиника: `center@demo.local`

## Проверки

```bash
mvn -f backend/pom.xml test
```
