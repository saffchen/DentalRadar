# Design

<!-- impeccable:design-schema 1 -->

## World

Медицинская карта пациента: бланк с графами, линейками и денежной колонкой. Не карточки. Плотная строка, тонкая линейка, цена справа на точечном выносе.

## Palette

| Token | Hex | Role |
|---|---|---|
| `--paper` | `#e8ece6` | фон страницы, бланковая бумага |
| `--sheet` | `#fbfcfa` | лист, панель, строка |
| `--ink` | `#1a2a2e` | текст, заголовки, правила-акценты |
| `--ink-soft` | `#4e5f5b` | подписи полей, адрес, служебный текст |
| `--rule` | `#c3ccc6` | линейки строк и таблиц |
| `--rule-strong` | `#7e8c87` | границы полей и кнопок, точечный вынос |
| `--action` | `#1f4e63` | главное действие, ссылки карты |
| `--action-soft` | `#dde7e2` | наведение строки, вторичная кнопка |
| `--selected` | `#d6e3dc` | выбранная строка |
| `--danger` | `#a23b2a` | удаление, ошибки |
| `--warn-bg` / `--warn-edge` | `#f6eed6` / `#8a6a1e` | предупреждение |

Контраст: ink/sheet 16.1:1, ink-soft/sheet 6.1:1, белый/action 7.7:1, белый/danger 7.5:1.

## Type

Golos Text, self-hosted (`frontend/public/fonts/`, `src/fonts.css`), 400/500/700, весовая ось переменная.

- Заголовок экрана: 1.5rem / 700 / -0.01em.
- Заголовок раздела: 1.125rem / 700.
- Название клиники: 1rem / 700 / -0.005em.
- Текст и поля: 0.9375rem, межстрочный 1.5.
- Подпись поля: 0.6875rem / 500 / 0.08em / uppercase, `--ink-soft`.
- Числа: `font-variant-numeric: tabular-nums` во всех ценах, оценках, счётчиках.

## Geometry

- Радиус 2px: поля, кнопки, панели, всплывающая карточка. Других радиусов нет.
- Тени не используются. Глубина — линейка и тон.
- Линейка 1px `--rule` между строками, 1px `--ink` под шапкой таблицы.
- Колонка списка 280–356px. Поле фильтра 300px и 190px. Страница 920px.
- Отступы: 1rem внутри листа, 1.5rem в панели, 0.8rem по вертикали строки.

## Components

- **Строка клиники** (`button.clinic-card`): имя и `4,0 из 5` на одной базовой линии, адрес, строки услуг `имя ····· цена`, число отзывов. Наведение — `--action-soft`, выбор — `--selected` и внутренний контур 1px `--ink`, фокус — контур 2px с отрицательным смещением.
- **Строка услуги** (`.service-line`): точечный вынос (`.service-lead`) тянет взгляд от названия к цене. Совпавшая с фильтром услуга — ink и 700 у цены.
- **Поле** (`label` + control): подпись над полем, uppercase, 0.6875rem. Поле 2.4rem высоты.
- **Кнопки**: главная — `--action`, вторичная — прозрачная с контуром, опасная — `--danger`. Кнопка выхода в топбаре — тихая текстовая ссылка.
- **Панель**: лист `--sheet` с линейкой 1px и радиусом 2px.
- **Таблица**: шапка uppercase 0.6875rem, значения с табличными цифрами, колонка цены — `.price`.

## States

| State | Treatment |
|---|---|
| hover | фон `--action-soft`, кнопки темнеют до `--action-dark` |
| active (нажатие) | фон `--selected` |
| selected (выбранная клиника) | фон `--selected` + `inset 0 0 0 1px --ink` |
| focus-visible | контур 2px `--ink`, смещение 2px; в строке — смещение −2px |
| disabled | непрозрачность 0.5, курсор default |
| empty | текст «Клиник не найдено. Измените услугу или оценку.» |
| error | `--danger`, `role="alert"` |
| loading | текст «Загрузка…» в строке счётчика, `role="status"` |

## Motion

Один приём: строки списка появляются с 0.24s `cubic-bezier(0.16, 1, 0.3, 1)`, сдвиг 4px, задержка 30ms по индексу. Других анимаций нет. `prefers-reduced-motion: reduce` отключает и переходы, и появление.

## Browser surfaces

- `::selection` — `#cfe0d9`.
- Полоса прокрутки — тонкая, `--rule-strong`.
- Focus ring и подчёркивание — из палитры, `text-underline-offset: 0.3rem`.
- Контролы карты Leaflet приведены к системе: 32px, радиус 2px, контур 1px, ink на листе.

## What this world refuses

- Круглые карточки, тени, скругления больше 2px.
- Заголовочные надстрочники (eyebrow) над заголовками.
- Средняя точка как разделитель и длинное тире внутри строки.
- Шрифт без поддержки кириллицы, системный serif в роли заголовка.
- Декоративные градиенты, стекло, моноширинный шрифт как костюм.
